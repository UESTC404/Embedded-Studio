# Embedded Studio Official Website

电子科技大学嵌入式工作室（Embedded Studio）官方网页，用于展示工作室介绍与相关文档。

## 管理员备注

- **编辑文档内容**：登录 [Pages CMS](https://app.pagescms.org/) 并选择 `UESTC404/Embedded-Studio` 仓库，即可在“网站文档（文件名即子链接）”中新增、修改或删除文档。修改文件名会同步改变网页路径，保存后网站会自动更新。
- **修改前端界面**：调整网页布局、样式或交互，需要将仓库代码克隆到本地进行开发、测试和提交。

以上操作均需要相应的 GitHub 仓库写入权限。
